# ApplyOnce WebExtension

ApplyOnce provides job-application autofill from one Manifest V3 HTML/CSS/JavaScript codebase for Safari on iOS and macOS, plus Chrome and Edge on desktop. It fills forms from a local profile, learns non-sensitive fields as you type, supports stored resume uploads, and includes a popup and full profile editor.

## One shared implementation

`ApplyOnce Extension/Resources` is the source of truth for every browser. It uses portable WebExtensions APIs and selects Safari's `browser` namespace or Chromium's `chrome` namespace at runtime.

| Browser | WebExtension code | Native container |
| --- | --- | --- |
| Safari on iPhone/iPad | Shared `Resources` | Existing iOS Xcode targets |
| Safari on macOS | Shared `Resources` | macOS wrapper generated by Apple's converter |
| Chrome/Edge on macOS, Windows, or Linux | Shared `Resources` | None |

The Swift handler is available only to Safari for optional native messaging. The current feature does not call it, so storage, matching, popup, editor, and autofill behavior remain shared JavaScript. Chrome and Edge on iOS do not currently load desktop WebExtensions; Safari is the supported iOS browser.

## Project layout

- `ApplyOnce/` contains the iOS app that explains how to enable the extension.
- `ApplyOnce Extension/` contains the Safari extension handler and WebExtension resources.
- `Documentation/AutofillEngine.md` describes autofill behavior and safety decisions.
- `Samples/ExampleProfile.json` is a sanitized example profile.
- `tests/` contains dependency-free manifest and JavaScript regression tests.
- `scripts/build-extension.js` stages the shared resources for Chrome and Edge.

The project uses Xcode file-system-synchronized groups. Add runtime web files directly to `ApplyOnce Extension/Resources`; Xcode includes them in the Safari extension target.

## Run on iPhone or iPad

1. Open `ApplyOnce.xcodeproj` in Xcode.
2. Select a development team for the `ApplyOnce` and `ApplyOnce Extension` targets if requested.
3. Select an iPhone/iPad simulator or device and run the `ApplyOnce` scheme.
4. Open **Settings → Apps → Safari → Extensions → ApplyOnce**.
5. Enable the extension and grant access to the required websites.

Safari controls site access independently of the manifest's `<all_urls>` request and blocks extensions on restricted pages.

## Run on Chrome or Edge

```bash
npm run build:chromium
```

Open `chrome://extensions` or `edge://extensions`, enable **Developer mode**, choose **Load unpacked**, and select `dist/chromium`.

Create `dist/ApplyOnce-chromium.zip` for distribution:

```bash
npm run package:chromium
```

## Run on Safari for macOS

Generate a macOS Safari wrapper that references the same extension resources:

```bash
xcrun safari-web-extension-converter --macos-only \
  "ApplyOnce Extension/Resources"
```

Leave resource copying disabled in the converter prompts. Configure signing for the generated app and extension targets, run the macOS app, and enable ApplyOnce under **Safari → Settings → Extensions**.

## Privacy

Profile fields, activity history, and selected resume bytes remain in local extension storage. ApplyOnce has no network service and does not send profile data to the containing app. Password, government-ID, payment, and banking fields are explicitly excluded.

Keep real exported profiles and resumes in the ignored `LocalData/` directory, never in `Resources` or `Samples`.

## Validation

Tests require Node.js 18 or newer and have no third-party dependencies:

```bash
npm test
```

Build the iOS Safari app and extension from a terminal:

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild \
  -project ApplyOnce.xcodeproj \
  -scheme ApplyOnce \
  -configuration Debug \
  -sdk iphonesimulator \
  -derivedDataPath /tmp/ApplyOnce-derived \
  CODE_SIGNING_ALLOWED=NO \
  build
```

## WebExtensions API compatibility

`storage.js` selects Safari's `browser` namespace when present and falls back to Chromium's compatible `chrome` namespace. The authoritative cross-browser manifest is in `ApplyOnce Extension/Resources`, with a non-persistent service worker and portable PNG icons.
